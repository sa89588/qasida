التعرّف الذكي على أي قصيدة

بدونه يتعرّف التطبيق فقط على القصائد الموجودة في الفهرس. بعد تفعيله يقرأ أي صفحة، حتى لو لم يكن فيها عنوان أو اسم شاعر، ثم يبحث عن تسجيلها في يوتيوب ويشغّله هنا. المفتاحان مجانيان، ويُحفظان على هاتفك فقط.

كيف أحصل عليه؟ (دقيقة واحدة)
  1. افتح aistudio.google.com/apikey وسجّل الدخول بحساب Google.
  2. اضغط Create API key ثم انسخ المفتاح والصقه هنا.
كيف أحصل عليه؟
  1. افتح صفحة YouTube Data API v3 بنفس حساب Google، واختر المشروع نفسه الذي أنشأه AI Studio، ثم اضغط Enable.
  2. من Credentials اضغط Create credentials ← API key وانسخه هنا. يكفي يومياً لنحو ٣٠ إلى ١٠٠ قصيدة جديدة.
  3. للحماية: افتح المفتاح واختر Websites وأضف sa89588.github.io/*

عند التعرّف الذكي تُرسل صورة الصفحة إلى Google لقراءتها. أما القصائد الموجودة في الفهرس فتُقرأ على هاتفك دون إرسال شيء.

البحث في صوت الشيعة

يبحث التطبيق في صوت الشيعة مع يوتيوب، ويشغّل التسجيلات بمشغّل صوت الشيعة نفسه داخل التطبيق. يعمل عبر Gemini إن كان مفعّلاً، والأسرع والأدق أن تنشئ خادم بحث صغيراً مجانياً (خمس دقائق، مرة واحدة).

كيف أنشئ خادم البحث؟
  1. افتح dash.cloudflare.com وأنشئ حساباً مجانياً (بريد وكلمة مرور).
  2. من القائمة اختر Compute (Workers) ثم Workers & Pages ثم Create، واختر Start with Hello World.
  3. سمّه qasida-search واضغط Deploy، ثم Edit code.
  4. اضغط الزر أدناه «انسخ كود الخادم»، وامسح الكود الموجود هناك والصق مكانه، ثم اضغط Deploy.
  5. انسخ رابط الخادم الذي يظهر (ينتهي بـ workers.dev) والصقه في الخانة أعلاه، ثم «احفظ واختبر».

سرعة التعرّف الذكي

«أسرع» يردّ عادة خلال ثانيتين إلى خمس ثوانٍ. جرّب «أدق» إن أخطأ في قراءة صفحة بخط صعب.
